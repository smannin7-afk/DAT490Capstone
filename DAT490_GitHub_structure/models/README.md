# Model Training Outputs

The evaluation notebook expects:

```text
outputs/predictions/heldout_predictions.csv
```

This file should contain the held-out 20% test-set labels, demographic columns used for fairness screening, and one denied-probability column per model.

Minimum expected columns:

```text
target
applicant_sex
applicant_age
prob_denied_logistic_regression
prob_denied_decision_tree
prob_denied_random_forest
prob_denied_xgboost
prob_denied_soft_voting_ensemble
```

The prediction file is generated by the model-training pipeline after the 80/20 stratified split with random seed 42. Do not commit the raw HMDA file.
